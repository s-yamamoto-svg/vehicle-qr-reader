車検証QR読み取り 組み込みパッケージ v1.1.0
============================================================

■ 中身
  index.php                  ロングラン補償申込フォーム(「車検証のQRコードから入力」ボタンを追加済み)
  qr/shaken-qr.js            読み取り・項目分解・転記の本体
  qr/vendor/                 読み取りエンジン(zxing-wasm)とPDF部品(pdf.js)。外部のCDNは使いません

■ 設置
  1. 既存の index.php をバックアップしてから、このフォルダの index.php で置き換える
  2. qr フォルダを、index.php と同じ場所にそのまま置く(index.php と qr/ が同じ階層)
  3. send.php など、他のファイルは変更不要です

■ 対応する車検証
  ・普通車: 国土交通省の二次元コード仕様(コード2=2分割、コード3=3分割。計5個)
  ・軽自動車: 軽自動車検査協会の仕様(コード2・コード3 各1個。計2個)。先頭の「K/22/」「K/32/」で判別します。
  ・紙の古い車検証(二次元コードなし)は読み取れません。
  ・軽自動車の仕様は、軽自動車検査協会の「各帳票に表示する二次元コードの仕様書」(2023.08.16 初版)に基づきます。

■ 動作条件
  ・ライブ読み取り(カメラ)は、ページが HTTPS で開かれているときだけ使えます。
    HTTP の場合は「撮影して読み取り」「PDF・画像ファイルから読み取り」だけ使えます。
  ・.wasm の MIME タイプ(application/wasm)の設定は不要です(自前で読み込んで起動します)。
  ・Content-Security-Policy を設定している場合は、同一オリジンの script と wasm の実行を許可してください。
    (script-src 'self' 'wasm-unsafe-eval' など)。現在の index.php には CSP の指定はありません。

■ 転記される項目(読み取り後に内容を確認してから「フォームに入力する」)
  登録番号 ← 二次元コード2の自動車登録番号
  車台番号 ← 二次元コード2の車台番号
  初度登録年月 ← 二次元コード3の初度登録年月(令和/平成に換算。昭和以前は入力しません)
  HV車 ← 二次元コード2の原動機型式。ハイフンで区切られた原動機の記載が2つ以上(例: R06A-WA05A)なら「はい」、1つなら「いいえ」
         型式なし・不明(*KUMITATE など)の場合は入力しません。
         ※ 一部のガソリン車は、1つのエンジンでも型式にハイフンを含む場合があり(例: 1NZ-FE)、「はい」と判定されます。確認画面で確認してください。
  排気量(cc) ← 軽自動車(コード2が「K/22/」で始まる)のとき660を入力します。
         電気自動車(燃料コード05)と、初度検査が1990年1月以前のものは入力しません(排気量が660ccでない場合があるため)。
         普通車の排気量は、QRコードに含まれないため手入力のままです。
  車名・用途・車両区分 ← 型式(二次元コード3)を、qr/data/models.json(OBD検査対象車型式一覧から作成)で引いて入力します。
         車名 = 通称名 / 用途 = 乗用・貨物 / 車両区分 = 乗用で国産なら「乗用」、輸入なら「外車」(貨物は入力しません)。
         ・型式が完全一致しない場合は、型式の前半(DBA-、3BA-など排出ガス規制の区分)を除いた後半が同じ車から推定し、画面に「推定」と表示します。
         ・一覧にない型式、通称名の記載がない型式、用途を決められない型式(乗合など)は、その項目を入力しません。
         ・メーカー名は確認画面に参考表示するだけで、フォームにも送信データにも入れません。
         ・用途を切り替えると補償期間の選択がやり直しになります(同じ用途なら触りません)。
  ※ 走行距離は、車検証のQRコードに含まれないため、手入力のままです。
  ※ 一覧は、OBD検査対象の型式だけです。載っていない車(古い年式など)は手入力になります。
  型式表を更新するとき: python3 build_models.py <新しいxlsx> <出力先>/qr/data/models.json を実行し、shaken-qr.js の ?v= を変えてください。

■ お客様向けモデル料金の表示(fee/)
  fee/fee.js     入力内容(用途・車両区分・HV・経過月・走行距離・排気量・補償期間)から料金表を引いて表示します。
  fee/fees.json  お客様向けモデル料金の表(仕切料金は含みません)。Accessの料金マスタから作成。
  ・補償期間の加算額: 12ヶ月 +3500円 / 24ヶ月 +4500円(3ヶ月は加算なし)。
  ・経過月は、初度登録年月から保証開始日までの暦月の差(日は見ません)。
  ・表にない組み合わせ(対象外)は「料金表に該当がありません」と表示します。
  ・料金表を更新したら、fees.json を差し替え、fee.js 内の DATA_VERSION を変えてください(キャッシュ対策)。
  ・仕切料金入りの社内確認用の表は、このパッケージに含めていません。公開しないでください。

■ 更新するとき
  qr/shaken-qr.js を差し替えたら、index.php の
    <script src="qr/shaken-qr.js?v=1.1.0" defer>
  の v= の値を変えると、各端末のキャッシュが更新されます。

■ 元に戻すとき
  バックアップした index.php に戻すだけです(qr フォルダは残っていても動作に影響しません)。
